ブロック入力診断ツール

問題を切り分けるための診断ツールです。各セクションで異なる側面をテストし、どこに問題があるか特定します。

1. サーバーからのデータ検証

サーバーから受け取ったデータを検証します。特にブロック名が正しく抽出されているかを確認します。

テストデータ: { "transcript": "ブロック名はS5です。現場では特に問題ありませんでした。", "summary": "現場報告: ブロック名S5で問題なし", "block": "S5" }

2. クライアント側入力テスト

ブロック入力欄へのデータ設定をテストし、問題がクライアント側にあるか確認します。

3. DOM要素検査

ページ上のブロック入力欄要素を検査し、正しく存在するか確認します。

4. 入力欄の値の変更検知テスト

入力欄の値の変更に関するイベントリスナーをテストします。

5. 総合フロー診断

要約からブロック名抽出 → 入力欄設定 → 候補表示の全フローをテストします。
