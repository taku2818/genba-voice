# 現場ボイス (Genba Voice)

造船会社における現場作業者向けの業務改善Webアプリケーションです。現場から音声で問題報告を行い、AIによる文字起こしと要約、ブロック名の推定を行います。

## 機能

- **音声録音**: ワンタップで音声録音を開始/停止
- **AIによる文字起こし**: OpenAI Whisper APIを使用
- **要約とブロック推定**: ChatGPTによる要約と104個のブロック候補からの推定
- **モバイル最適化UI**: 現場での使いやすさを重視したシンプルなインターフェース
- **船体番号管理**: 最近の船体番号を表示、選択または手入力可能

## セットアップ手順

### 前提条件

- Node.js (v14以上)
- npm または yarn
- OpenAI API キー

### インストール

1. パッケージをインストールします:

```bash
npm install
```

2. `.env.example` ファイルをコピーして `.env` ファイルを作成し、OpenAI APIキーを設定します:

```
PORT=3001
OPENAI_API_KEY=your_openai_api_key_here
```

### 実行

開発モードで実行:

```bash
npm run dev
```

本番モードで実行:

```bash
npm start
```

サーバーが起動したら、ブラウザで `http://localhost:3001` にアクセスします。

## 使い方

1. 名前を入力してログイン
2. 船体番号を選択または入力
3. 「音声報告開始」ボタンをタップして録音開始
4. 問題内容を音声で報告（ブロック名や具体的な不具合を説明）
5. 録音停止後、AIによる文字起こしと要約が表示され、適切なブロック名が推定されます
6. 内容を確認し、必要に応じて修正してから「確定」ボタンをタップ
